# ピント連写テスト(ステップ1)手順書

iPhoneのカメラで、レンズ位置(0.0=近い〜1.0=遠い)を段階的にずらしながら3枚連写し、端末内に保存できるかを確かめる最小アプリです。
Windowsだけ・無料(GitHub Actions + Sideloadly)で、実機に入れるまでの手順です。

## 0. 構成
- アプリ本体: Expo + react-native-vision-camera v5(`setFocusLocked` でレンズ位置を固定)
- ビルド: GitHub の macOS 上で **署名なし** の .ipa を作る(`.github/workflows/build-ios.yml`)
- 署名・インストール: Windows の Sideloadly(無料の Apple ID で署名。約7日で失効)

## 1. GitHub にアップロードしてビルド
1. GitHub でリポジトリを新規作成する(名前は自由)。
   - **公開(Public)なら Actions は無料**。非公開(Private)だと macOS の実行時間が無料枠から多めに引かれる(10倍換算。最新の規定は GitHub の料金ページで確認)。このテストのソースに秘密は含まれないので、公開で問題ありません。
2. このフォルダの中身(`node_modules` と `ios` は無い状態)を、そのままリポジトリへ入れる。
   - Git が使える場合:
     ```
     cd focustest
     git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
     git add -A && git commit -m "init" && git branch -M main && git push -u origin main
     ```
   - Git が無い場合: リポジトリの画面で「uploading an existing file」からフォルダごとドラッグ。`.github` フォルダ(隠しフォルダ)も忘れずに。
3. リポジトリの **Actions** タブ → 「Build unsigned IPA」→ **Run workflow**(push 時にも自動で走ります)。
4. 完了(15〜30分程度)したら、実行結果の下部「Artifacts」から **focustest-ipa** をダウンロードして展開し、`focustest.ipa` を取り出す。
   - 失敗した場合は、赤くなった手順(Step)のログ末尾をそのまま私に貼ってください。初回は調整が要る可能性があります。

## 2. iPhone に入れる(Sideloadly)
1. Sideloadly の公式サイトからインストールする。Windows では、Sideloadly の案内に従い、iTunes と iCloud(Apple 公式サイト版)も必要です(インストール画面の指示を確認してください)。
2. iPhone を USB で接続し、「このコンピュータを信頼」する。
3. Sideloadly に `focustest.ipa` をドラッグし、Apple ID を入力して **Start**。
4. iPhone 側の設定:
   - 設定 → プライバシーとセキュリティ → **デベロッパモード** をオン(再起動が必要)
   - 設定 → 一般 → VPNとデバイス管理 → 自分の Apple ID を **信頼**
5. ホーム画面の「ピント連写テスト」を開き、カメラを許可する。

注意: 無料の Apple ID の署名は **約7日で切れます**。切れたら同じ手順で入れ直します(データはアプリを消すと消えます。写真アプリへ保存したものは残ります)。

## 3. 試すこと
1. 小さい被写体(葉・花など)を、画面の手前〜奥に奥行きがある状態で置く。
2. 「ピントをずらして 3枚 撮影」を押す。
3. 見るポイント:
   - **指定** のレンズ位置と **実測** がほぼ一致しているか(一致すれば `setFocusLocked` が効いている)
   - 3枚のピントの合っている場所が、手前→奥と変わっているか(「写真アプリにも保存」で拡大して確認)
   - レンズ(標準・超広角・望遠)ごとの動き。近い被写体は「超広角(マクロ)」で試す
   - 「レンズ停止待ち」を短くしてもピントがずれないか(200ms / 400ms / 800ms)
4. 保存先: アプリ内の `focus_test/<日時>/`。「ファイル」アプリ → このiPhone内 → このアプリ のフォルダからも開けます。

## 4. 結果の返し方
次の4点を教えてください。次のステップ(WebView・既存システムへの送信)の設計に使います。
- 指定と実測の値(例: 0.2→0.2、0.5→0.5…)
- ピントが実際に動いたか
- 使えたレンズ(標準・超広角・望遠)
- 撮影にかかった時間(体感でよい)
