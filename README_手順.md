# 植物管理クライアント(iPhone / iPad)v2 手順書

既存の植物管理システム(https://192.168.0.143:8001)をアプリ内で開き、カメラの「写真」と「ピント合成」だけを、レンズ位置を固定できるネイティブ撮影に差し替えるアプリです。
**サーバー側の変更はありません。** 撮影結果はページ自身の保存処理(ログイン・CSRF 込み)に渡されます。

## 1. 更新のしかた(前回のリポジトリを使う)
1. このフォルダの中身で、リポジトリの同名ファイルを置き換える(`App.tsx`・`src/`・`app.json`・`package.json`・`package-lock.json`・`.github/workflows/build-ios.yml` など)。
   - 古い `README_手順.md` や、削除された依存(`expo-media-library`)は `package.json` の更新で自動的に外れます。
   - `.github/workflows/build-ios.yml` は、前回のとおり GitHub の画面から作成/更新してください。
2. Actions → 「Build unsigned IPA」→ Run workflow。成果物は **plant-client-ipa**(中身は `plant-client.ipa`)。
3. Sideloadly で `plant-client.ipa` を入れる(Apple ID・デベロッパモード・信頼の手順は前回と同じ)。

注意:
- アプリ名・識別子が変わったため、**別のアプリとして入ります**。無料の Apple ID は同時に入れられるアプリ数に上限があるので、前回の「ピント連写テスト」は削除してください。
- iPad にも同じ .ipa を同じ手順で入れられます。

## 2. 最初に確認すること
1. アプリを開くと、システムのログイン画面が出ます。ログインしてください(その後は保持されます)。
2. 開けない場合は、赤い枠に理由が出ます。
   - 同じ Wi-Fi(自宅内)につながっているか
   - **iPhone の Safari で `https://192.168.0.143:8001` を開けるか**。Safari で警告なしに開ければ、アプリでも開けます(証明書の信頼設定は端末共通です)。
   - 初回は「ローカルネットワークへのアクセス」を許可してください。
3. アドレスを変えたいときは、右下の ⚙ から変更できます。

## 3. 試すこと
1. 個体・資材などの写真欄の「📷 カメラで撮って登録」を押す(ファイル管理のカメラボタンも同じ)。
2. アプリ専用の撮影画面が開く。
   - **写真**: 「撮影して保存」→ ページの保存処理で登録される。
   - **ピント合成**: レンズ・枚数・範囲を選び「ピントをずらして N枚 撮る」→ サムネイルの下に「指定/実測」が出る → 「ピント合成して保存」→ サーバーで合成されて登録される。
3. 画面の上部に、**実際に使われているレンズ名と種類**が出ます(標準/超広角/望遠を選んでも、機種に無い場合は別のレンズになります。その場合は注意書きが出ます)。
4. 動画・QR は従来の Web 版カメラが開きます(撮影画面の「動画(Web版カメラ)」「QR(Web版カメラ)」から)。

## 4. 今の制限(把握済み)
- **撮影場所の記録は付きません**(Web 版カメラは位置情報を付けていたが、ネイティブ撮影では未対応)。次の段階で追加できます。
- 画像は WebView へ base64 で渡すため、枚数が多いと送信に時間がかかります(通常の 12 メガ画素で 5〜9 枚が目安)。
- 外出先(自宅の外)からは、サーバーに届く経路(VPN など)が無いと開けません。
- 無料の署名は約 7 日で切れます(同じ手順で入れ直します。ログインはやり直しになる場合があります)。

## 5. 結果の返し方
- ピント合成まで保存できたか(個体の写真欄・ファイル管理で確認)
- 「使用中」に出たレンズ名と種類(標準・超広角・望遠の各選択時)
- 指定と実測のレンズ位置の値
- 画面が崩れる・ボタンが反応しない箇所があれば、そのページ名
