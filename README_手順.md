# 植物管理 iPhone / iPad アプリ(v3.6)手順書

## 0. 前回(v2)から入れ替える場合
- GitHub の既存ファイルを、このzipの中身で**上書き**してください(`.github` と `assets` フォルダも含めて全部)。
- 新しい機能(位置情報・通知)のため、**アプリ内容が変わります**。Sideloadly で入れ直すと、同じアプリの上書きになります(前の植物管理アプリを先に消す必要はありません)。
- 無料の Apple ID では同時に入れられるアプリは3つまでです。ほかのアプリで枠が足りない場合は、いらないものを消してください。

## 1. GitHub にアップロード
1. リポジトリの中身をこのzip内のファイルで置き換える(`.github/workflows/build-ios.yml` と `assets/` の6枚のPNGを忘れずに)。
2. 「Actions」→「Build unsigned IPA」→「Run workflow」。10〜20分で完了。
3. 完了後、`plant-client-ipa` をダウンロードして展開 → `plant-client.ipa`。

## 2. Sideloadly で入れる
1. iPhone / iPad を Windows に接続、Sideloadly に `plant-client.ipa` をドラッグ。
2. Apple ID を入れて「Start」。
3. iPhone/iPad の「設定 → 一般 → VPNとデバイス管理」で自分のApple IDを信頼。開発者モードはオンのまま。
4. 7日で期限が切れるので、週1回 Sideloadly で入れ直してください。

## 3. 初回の許可
- カメラ / 位置情報(使用中のみ)/ 通知 / ローカルネットワーク を求められたら、すべて「許可」。
- 通知は、右下ではなく左下の ⚙ → 「予定・期限を通知する」をオンにしたときに許可を求めます。

## 4. 使い方
左下に3つのボタンがあります。
- 📷 **クイック撮影(圏外でも使えます)**: 撮った写真は端末に貯め、つながると自動で送信。赤い数字は未送信の件数。QRを読ませると、その記録に紐づけて送ります。
- 🔎 **調べもの**: iPad(横向き・幅が広いとき)は右側に分割表示。iPhone は全画面で開きます。画面を**長押し**すると、選んだ文字・リンク・画像を「一時メモに追加」「ファイル管理に保存」「検索」に送れます。
- ⚙ **設定**: システムのアドレス、撮影場所の記録、通知、未送信の確認・今すぐ送信。

ホーム画面のアイコンを長押しすると「クイック撮影」「QRを読んで撮る」が出ます。

システムの画面からカメラを開いた場合(ファイル管理・QR連続撮影など)も、写真・ピント合成・QRは自動でこのアプリのカメラに切り替わります。動画だけはWeb版カメラです。

### カメラの機能
- **レンズ**: 0.5x / 1x / 2x / 望遠 を倍率ボタンで切り替え(以前の「レンズがありません」はこの方式で解消する想定)。
- **ピント範囲のタップ指定**: 「タップで自動指定」→ 手前の端 → 奥の端 の順にタップ。
- **ピント合成**: 「写真で(高画質)」または「動画から(短時間・実験)」を選べます。
- **三脚モード / タイマー**: 三脚モードはピント移動後の待ちを長くします。タイマーは3秒・10秒。
- **撮影場所**: 設定でオンなら、保存時に位置情報を添えます。

## 5. 試して教えてほしいこと
1. 倍率ボタン(0.5x・1x・2x・望遠)で画面の見え方が変わるか。ピント合成のとき各倍率で撮れるか。
2. 「動画から」のピント合成と「写真で」のピント合成の仕上がりの比較(画質・所要時間)。
3. 機内モードで📷から撮影 → 赤い数字が増える → 機内モードを切る(VPN接続)と自動で送信されるか。サーバーのファイル管理に入っているか。
4. QR読み取り(クイック撮影のQRタブ、およびQR連続撮影ページ)で読めるか。
5. 位置情報がファイルの撮影場所に入っているか。
6. 通知が設定した時刻に来るか(設定で「通知を今すぐ更新」→ 件数が出るか)。
7. iPad で 🔎 → 右側に調べもの画面が出るか。長押しメニューで一時メモ追加・画像保存ができるか。
8. ホーム画面アイコン長押しのメニュー。
うまくいかない場合は、画面に出たメッセージを、そのまま(またはスクリーンショットで)教えてください。

## 5.5 v3.2 での変更

- ファイルのダウンロードは、アプリ内で取得して端末に保存し、共有メニュー(「ファイルに保存」など)を出します。
- 調べものの最初のページは、システムのブックマーク一覧になりました(リンク集・検索のボタンもあります)。
- 文字を選ぶと、iOS標準のメニューに「一時メモに追加」「検索」「ページをブックマークへ」が出ます。リンク・画像の長押しでは、メモ / ファイル管理 / ブックマーク / リンク集 への登録メニューが出ます。★ボタンで今のページを登録できます。
- 圏外のとき、送信の表示がちらつかないようにしました(失敗後は60秒あけて再試行)。

## 5.6 v3.4 での変更
**保存が止まる不具合の修正**
- ファイル管理のカメラで「保存中」から進まなかった件: サーバーへ届いた時点で「保存済み」と見なすようにしました(ページ側の一覧の再読み込みは待ちません)。
- 保存は裏で順番に行い、保存中でも続けて撮影できます(画面左下に「裏で保存中 N件」)。
- 保存に失敗しても撮った写真は消さず、「未送信の撮影」に確認待ちで残します。送れたか分からないとき(応答なし)も同じで、二重登録を避けるため自動では再送しません。

**撮影**
- ピント合成の連写中は、明るさ・色を固定します(設定でオフ可)。
- 撮った写真を送る前に確認する(設定)。連写は、ぶれたコマをタップして合成から外せます。
- グリッド線と水準器(設定)/ ライト(iPhone のみ)/ 撮影中は画面を暗くしません。
- 送る写真の大きさ(そのまま・2048px・1280px)/ 写真アプリにも保存(設定)。
- 外部キーボード(スペース / Enter)で撮影(設定。iPad のキーボード用)。

**安全・運用**
- 未送信の撮影を、写真アプリへ退避できます(未送信の画面)。
- アプリの期限(7日)を設定画面に表示し、前日に通知します。残り2日以内は画面上部に警告を出します。
- Face ID(または端末の passcode)で開く設定。1分以上はなれると、もう一度確認します。
- 診断画面(版・ビルド日時・期限・最後につながった時刻・動作の記録・接続確認)。設定から開けます。

**調べもの**
- 複数のタブ(最大8)/ ページ内検索 / 閲覧履歴。長押しの「リンク先を開く」は新しいタブで開きます。

**サーバー側(任意)**
- 撮影ごとの番号 `client_id` を、保存の通信(upload / stack)に添えています。サーバーがこれを使って二重登録を防ぐようにすると、通信が途切れたときの重複を完全に避けられます(未対応でも動きます)。

## 5.7 v3.5 での変更
- 撮影画面の上の「メニューを隠す / 出す」で、設定欄を隠して映像を大きくできます(隠すと、下にシャッターだけが残ります。次に開いたときも引き継ぎます)。
- 撮った直後の確認(設定でオン)は、画面いっぱいに大きく表示します。ピント合成の連写は、選んだコマを大きく表示し、「合成から外す」ボタンで外せます。
- 調べもの: 文字を選んだときのメニューから「ページをブックマークへ」を外しました(ページの登録は ★ ボタン)。リンクの長押しは、iOS標準のメニュー(Open Link など)ではなく、こちらの登録メニューが出る設計に変えました。

## 5.8 v3.6 での変更
**ラベルの文字を読む(OCR)**
- 撮影画面の「ラベルの文字を読む(OCR)」を押すと、ラベルを撮って文字を読み取ります(iPhone 標準の文字認識。日本語・英語)。ボタンを押したときだけ動きます。撮った写真は保存しません。
- 読み取った行ごとに「記録に紐づける」(QR を読んだのと同じ扱い)と「名前に入れる」(ファイル名。クイック撮影のみ)を選べます。
- ピント合成の「動画で撮る」方式のときは、カメラの都合でOCRは使えません(「写真で」を選ぶと使えます)。

**ショートカット・Action Button からの起動(URLスキーム)**
- `plantapp://quick/photo`(クイック撮影)/ `plantapp://quick/burst`(ピント合成)/ `plantapp://quick/qr`(QR)/ `plantapp://research?url=https%3A%2F%2F…`(調べもので開く)/ `plantapp://settings` / `plantapp://diag`(診断)/ `plantapp://import`(ファイルの取り込み)
- ショートカットアプリで「URLを開く」にこのアドレスを入れると、アプリの該当画面が開きます。Action Button にそのショートカットを割り当てると、押すだけで撮影画面が開きます。
- Face ID の設定がオンのときは、確認が済んでから開きます。

**ファイルの取り込み**
- 設定の「ファイルを取り込む(ファイルApp・AirDrop)」で選んだファイルを、ファイル管理へ送ります。ファイルAppや AirDrop で「植物管理で開く」を選んでも、同じように取り込みます(画像・PDF・テキスト・動画)。
- 1ファイル30MBまで。大きいものはパソコンから取り込んでください。通信できないときは取り込めません(圏外用の順番待ちには入りません)。

## 5.9 v3.7 での変更
**下のバーを1つに統一**
- サーバー画面の下バーは隠し、アプリの下バーだけにしました: ホーム / 植物 / 記録 / 撮影 / メモ / その他。いまいるページは緑で表示します。
- 「その他」に、調べもの・今の画面を保存・スクショ取り込み・書類スキャン・ファイル取り込み・カレンダー書き出し・設定をまとめました。
- 「メモ」は、押すとすぐ書ける画面が開き、一時メモに追加します。

**ファイル管理への取り込みが増えました**
- 今の画面を画像で保存 / スクショ・写真を選んで取り込み(複数可)/ 書類スキャン(自動で台形補正してPDF化)。
- スクショを撮ると「取り込みますか?」と尋ねます(設定でオフにできます)。

**撮影**
- 2本指で拡大・縮小、画面タップでピント合わせ。前回のモードとズームを覚えます。
- バーコード(EAN / UPC / Code128 など)も QR と同じに読みます。
- OCR で読んだ文字から「記録を探す」で、候補を選んで紐づけられます。
- 撮影・保存の完了を振動で知らせます(設定でオフ)。

**iPhoneならではの機能**
- 予定をカレンダー「植物管理」へ書き出し(毎回入れ替えるので重複しません)。
- 温室に着いたら、今日の作業を通知(設定 → iPhoneならではの機能 → 今いる場所を温室にする)。「常に許可」が必要で、無料の署名では動かない可能性があります。

**使いやすさ**
- メッセージは下に出し、エラーは分かる日本語にしました。設定は項目ごとに開閉します。未送信の一覧に写真の縮小画像、取り込みの進み具合の表示、診断の共有ボタンを足しました。

**未実装**: 背景を消す加工(ネイティブ部品が必要で、ビルドを壊すおそれがあるため見送り)。

## 6. できないこと・制限
- 通知は「アプリを開いたとき」にサーバーの一覧から予約し直します。アプリを数日開かないと、新しく追加された予定は通知されません。
- 他のアプリからの共有メニューでの受け取り(Share Extension)は、無料のApple IDでは安定して作れないため入れていません。外部キーボードは、撮影のスペース / Enter のみ対応で、調べものの画面のショートカット(Cmd+Lなど)はありません。Bluetooth リモコンの音量ボタンでの撮影も未対応です。共有からの登録は、iOSの「ショートカット」アプリ経由の方法を別途ご提案できます。
- 無料のApple IDでは、アプリの期限が7日です。
- 圏外で撮った分は、アプリを開いたときや90秒ごとに送信を試みます。アプリを完全に終了していると送られません(次に開いたときに送信)。
- 動画から取り出すピント合成は実験機能で、画質が写真より下がる想定です。
